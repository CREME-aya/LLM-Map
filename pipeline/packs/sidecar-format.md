# 有向辺属性 sidecar v1

この固定長形式はホスト PoC の生成側・読取側が共有する。正式なマニフェストにはタイル、グラフ版、生成コミット、GraphTile と sidecar の SHA-256 を対応付ける。配信チャンクから検証済みの非圧縮ファイルを展開し、読み取り専用 mmap で使う。整数はリトルエンディアン、パディングはない。

| オフセット | 長さ | 内容 |
|---|---:|---|
| 0 | 4 | ASCII `DSC1` |
| 4 | 2 | 形式版 u16 = 1 |
| 6 | 2 | レコード幅 u16 = 4 |
| 8 | 8 | 有向辺の所属タイルを示す u64（階層を含む Valhalla tile base GraphId の値） |
| 16 | 32 | マニフェストの graph_version の UTF-8 バイト列の SHA-256 生値 |
| 48 | 4 | タイル内有向辺数 u32。グラフ生成時に DirectedEdge 配列と同順で出力 |

有向辺のタイル内 index `i` はレコード `52 + 4*i` に対応する。逆方向辺も固有の index で引く。レコード内の 0–1 は確認済み道路幅 cm (u16)、2 は確認済み車線数 (u8)、3 は属性タグビット。bit 0 は関連信号情報の存在、bit 1 は道路幅の存在、bit 2 は車線数の存在、bit 3 は方向対応済み turn:lanes の存在。上位4ビットはゼロ。幅・車線数は該当ビットが立つ場合のみ正値で、それ以外はゼロとする。信号・右折レーンの存在は保護現示の証拠に使わない。

有効なレコードでビットが無い属性は Unknown。読取前にファイルハッシュ、版、タイルキー、有向辺数、ファイル長、レコード整合性を検証する。欠落、切断、範囲外 index、対応グラフとの不整合は不完全データとして拒否する。新たな属性値の追加は形式版とレコード幅を更新する。

共通の最小検体は `pipeline/harness/handoff/fixture.dsc`（graph_version は jp-test-1、tile base は 0、2辺）である。
