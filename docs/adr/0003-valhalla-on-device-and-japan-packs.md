# ADR-0003: 端末内 Valhalla C++ と日本全国固定版配布

- **ステータス**: Accepted
- **日付**: 2026-11-20

## コンテキスト
本アプリは「基本無料・一般公開」「最初から日本全国 47 都道府県対応」「オフライン自前ターンバイターンナビ」を掲げており、運営サーバで経路計算や商用プローブ API 課金を負担する構成は持続しない。また、OSMF 公開タイルの一括キャッシュは利用規約上認められていない。

## 決定
1. **経路エンジン**: GraphHopper（Android オフライン公式サポート終了）および OSRM（CH/MLD の動的制約柔軟性・NDK 同梱制約）ではなく、**Valhalla C++** を端末内オフラインエンジンとして採用する。`Rallista/valhalla-mobile 0.6.2` の NDK r29 / CMake / Ninja / vcpkg 構成を出発点としつつ、既存 AAR の PBF 非対応制約および再相関ズレを防ぐため、**同一 Actor 呼出しから `Trip` と `Directions` の有向辺情報を抽出する薄い C++ 境界** を追加する。
2. **日本全国一括固定版生成と R2 配布**: 47 都道府県ごとに個別グラフを生成せず、専用 Linux（または Windows WSL2 Docker）ビルド機で固定版の日本 PBF から全国一括で `Planetiler` (PMTiles) ＋ `Valhalla Mjolnir`（L0/L1/L2・同版有向辺属性 sidecar）＋ ABR/文化財・歴史 SQLite を生成し、**Cloudflare R2** から署名付きマニフェスト・≤256 MB チャンクで地域・再探索回廊単位に配布する。

## 検討した代替案
- **サーバ側での経路 API 提供**: 無料公開時の利用者増加によるサーバ費・帯域費破綻を避けるため不採用。
- **都道府県単位の独立グラフビルド**: 県境跨ぎや長距離ドライブでのルート連続性と `L0/L1` 階層探索が破綻するため不採用。

## 影響とトレードオフ
- **利点**: 端末内で完全オフライン経路探索・再探索が可能になり、R2 直接 egress 無料枠を活かして個人でも日本全国対応を維持しやすい。
- **制約**: Android 最終 AAB の 16 KB ページ対応、生成側と端末側 Valhalla コミットの一致、および R2 の月次無料枠（10 GB-month 保存・Class B 1,000 万回）を監視する配布ゲートが必須となる。

## 再評価条件
- PoC Gate 1（16 KB ページ対応・同一呼出し有向辺取得）または Gate 2（全国生成サイズ・R2 無料枠予算）が未達の場合、上流 Valhalla 最小ターゲットの自前 CMake 構築や配布圧縮/対象分割単位の見直しを行う（PC 上の成功だけで Android 対応と見なさない）。
